# Strofas (στροφή — «поворот, виток»)

Круговое меню-лаунчер для Windows в духе radial-меню из VRChat: нажал горячку —
меню из «лепестков» под курсором, вёл мышь, кликнул — программа запущена.
Запуск и остановка portable-программ, вложенные категории, GUI-редактор.

## Управление

| Действие | Результат |
|---|---|
| **Ctrl+B** (настраивается) | показать / скрыть меню |
| Движение мыши | подсветка лепестка (акцент темы + пружинный масштаб), подпись в центре |
| Левый клик по пункту | выполнить действие |
| Левый клик по категории | открыть вложенный круг |
| Клик по центру | «Назад» (если открыта категория) или закрыть |
| **ПКМ** / **Backspace** | назад / закрыть |
| **Esc** | закрыть |
| **←→↑↓ / Enter** | выбор пункта с клавиатуры |
| **Колесо мыши** | листание страниц, если в кольце > `maxItemsPerRing` пунктов |
| **ПКМ по лепестку** | контекстные действия: открыть папку, запуск от администратора, копировать путь, редактор |
| Клик по пустоте | закрыть |

Меню появляется там, где сейчас курсор, курсор переносится в центр круга.

## Дизайн (v3)

- **Прозрачное окно** — видны только кнопки: лепестки и хаб, квадратной подложки нет.
- **Живое размытие под лепестками**: каждый лепесток показывает блюр того, что
  за ним, кадр обновляется ~36–50 раз/сек (захват экрана в фоновом потоке,
  `SetWindowDisplayAffinity` исключает само меню из захвата — нет «призраков»).
- **Материал**: поверх каждого лепестка — процедурное **зерно/шум** (без файлов,
  один frozen-кисть на процесс), **тени-парение** (чёрная мягкая тень), на
  hover — **акцентное свечение (bloom)**: тень перекрашивается в акцент,
  BlurRadius и opacity растут с пружинной анимацией.
- **Стеклянные чипы**: буква/иконка пункта — в круглой стеклянной подложке
  (3-stop градиент, двойная обводка светлое-сверху/тёмное-снизу, тень);
  на hover рамка становится акцентной, тень — свечением.
- **Трек-кольцо** — тонкое градиентное кольцо под лепестками (механизм колеса).
- **Псевдо-перспектива при открытии**: колесо «разворачивается» из наклона
  (SkewTransform + коллапс ScaleY — имитация поворота; в .NET 10 WPF нет
  `PlaneProjection`), кик наклона при погружении в категорию/возврате.
- **Акцент из темы Windows** (`DWM\AccentColor`, живое обновление при смене темы;
  можно переопределить `"accent": "#hex"` в конфиге) — один общий акцент,
  без per-category раскраски.
- Геометрия: колесо меньше (край ~46% размера окна), зазор между лепестками 8° —
  лепестки стройнее и «продольнее».
- **Область наведения больше самой кнопки**: угловые зазоры кликабельны (0°),
  радиус заходит за кромку на ~6 px, гистерезис ±6 px против мерцания (Fitts: цель
  больше — ошибок меньше).
- **Анимации**: spring-стаггер входа (BackEase), доворот колеса, hover с пружиной,
  **press-in** при клике, пульсация зелёной точки «запущено»,
  **idle-дыхание хаба** (мягкая пульсация кольца), проворот колеса при смене
  страницы (BackEase-инерция).
- **Указатели**: пунктирная **линия-ретикуль** от центра к активному сектору и
  **chevron-указатель** у внутренней кромки сектора (приём Coherent/Gameface).
- **Хаб**: pill-бейдж статуса (акцентный для github-состояний, нейтральный для
  breadcrumb пути), подпись пункта, подсказка действия, **пилюли-индикаторы
  страниц** (активная — вытянутая).
- **Reduced motion** (`SPI_GETCLIENTAREAANIMATION`, системная настройка
  «Анимации Windows»): без стаггера, вращения и пружин — только быстрый fade.

## Сборка

Требуется .NET SDK 10+.

```powershell
debug.bat                        # консоль управления: сборка, запуск, лог, git
debug.bat 1                      # и сразу выполнить пункт (1 — сборка и запуск)
dotnet build Strofas.slnx                 # отладочная сборка
dotnet run --project src/Strofas           # запуск из исходников
dotnet run --project src/Strofas -- --menu # сразу показать меню (для отладки)
dotnet run --project src/Strofas -- --editor # сразу открыть редактор
```

Portable-однофайловый exe (self-contained, не требует .NET на целевой машине):

```powershell
dotnet publish src/Strofas -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
# результат: src/Strofas/bin/Release/net10.0-windows/win-x64/publish/Strofas.exe
```

Отладочные флаги окружения:
- `STROFAS_NO_EXCLUDE=1` — не исключать меню из screen-capture (чтобы меню
  попадало в скриншоты; в обычном режиме оно исключено, иначе живой блюр
  ловит сам себя).

## Конфигурация

`%LOCALAPPDATA%\Strofas\menu.json` — создаётся автоматически с примером при первом
запуске. Правится руками или через редактор (трей → «Редактор меню»).

```jsonc
{
  "hotkey": "Ctrl+B",          // горячка-переключатель
  "closeAfterAction": true,    // закрывать меню после действия
  "menuSize": 640,             // размер окна меню, DIP (400..1200)
  "maxItemsPerRing": 8,        // максимум пунктов на кольцо (дальше — страницы)
  "accent": "auto",            // "auto" — из темы Windows, либо "#5B9DFF"
  "items": [
    { "label": "Блокнот", "action": { "type": "launch", "path": "notepad.exe" } },
    {
      "label": "Утилиты",      // пункт с children = категория (вложенный круг)
      "children": [
        { "label": "Остановить блокнот",
          "action": { "type": "stop", "processName": "notepad" } }
      ]
    }
  ]
}
```

Поля `action`:

| Поле | Назначение |
|---|---|
| `type` | `launch` — запуск, `stop` — остановка, `toggle` — запуск/остановка |
| `path` | exe / файл / папка / URL; поддерживаются `%APPDATA%` и т.п. |
| `args` | аргументы командной строки |
| `workingDir` | рабочая папка |
| `processName` | имя процесса без `.exe` — для `stop`/`toggle`, а также индикатора «запущено» |
| `hidden` | `true` — запускать скрытым окном |

Иконка пункта: `icon` — путь к `ico/png/exe/dll` (для exe берётся его иконка).
Без иконки — **автоматически иконка из `path`** (exe/dll), иначе первая буква
названия.

### Быстрое добавление пунктов

- **Перетащите файлы из проводника в окно редактора** — на каждый создаётся
  пункт: подпись из имени файла, путь, иконка подтягивается автоматически.
  Ярлыки `.lnk` разрешаются до реальной цели (имя и иконка настоящей программы).
- **Укажите путь в поле «Путь»** — если подпись пустая или «Новый пункт»,
  она заполняется именем файла автоматически.
- В дереве редактора пункты **перетаскиваются мышью**: вверх/вниз для порядка,
  на категорию — внутрь (середина узла), на край узла — вставить до/после.
  Запрещено перетащить категорию в неё самую или в её потомков.

### Остановка процессов

- Если пункт запускал программу из меню, «стоп» бьёт по запомненному PID
  (сначала мягко — `CloseMainWindow`, затем `Kill` всего дерева).
- Иначе — по `processName` из конфига: убиваются все процессы с этим именем.
- Зелёная точка на лепестке — программа запущена (по PID или `processName`;
  для программ-заглушек вроде `notepad.exe` на Win11 заполняйте `processName`).

### Приложения из GitHub-релизов (`type: "github"`)

Пункт меню может ставить и **автообновлять** exe из релизов GitHub — например
`https://github.com/vilminessa/PoTaskojo/releases`:

```jsonc
{
  "label": "TaskScope",
  "action": {
    "type": "github",
    "repo": "vilminessa/PoTaskojo",   // или полная ссылка на releases
    "asset": "taskscope.exe",         // имя exe-ассета в релизе
    "tag": "latest",                  // или "v1.2.3" для пиннинга
    "autoUpdate": true,               // фоновое авто-обновление
    "sha256": ""                      // опционально: пиннинг хеша ассета
  }
}
```

Как это работает:

- **Проверка версии** — при каждом открытии меню, асинхронно, через редирект
  `github.com/.../releases/latest` — **без квоты GitHub API** (API нужен только
  редактору для списка ассетов и кэшируется по ETag).
- **Состояния**: не установлено → клик ставит (с прогрессом в хабе) и запускает;
  есть новая версия → **лепесток делится на две зоны**: внутренняя — «Запустить»
  текущую, внешняя с глифом `↑/↻/✓` — «Обновить».
- **Авто-обновление** (по умолчанию): при открытии меню новая версия качается
  в фоне; если процесс запущен — копия кладётся в `staging` и применяется при
  следующем открытии меню (рабочий exe перезаписать нельзя).
- Файлы: `%LOCALAPPDATA%\Strofas\apps\{owner}\{repo}\` (exe + `version.txt`).
- В редакторе: тип `github`, поле репозитория принимает любую ссылку на releases,
  кнопка «Проверить» подставляет последний тег и список ассетов (выпадающий
  список вместо ручного ввода имени файла).
- Опционально в корне конфига: `"githubToken": "ghp_..."` — повышает лимит
  GitHub API для списка ассетов (без токена работает тоже, лимит меньше).

### Вложенность

Категории вкладываются без ограничений: клик по категории погружается глубже,
наведение на корневое кольцо — превью на глубине ≤1 (глубже путь не теряется),
ПКМ/Backspace/центр — назад по одному уровню, breadcrumb показывает весь путь.

## Редактор (трей → «Редактор меню»)

- дерево структура меню: добавить пункт / категорию (в выбранную группу),
  переупорядочить, удалить — вложенность любого уровня;
- свойства выбранного пункта: название, иконка, тип действия, путь, аргументы,
  рабочая папка, имя процесса, скрытый запуск;
- живой предпросмотр круга с подсветкой при наведении;
- горячка, размер меню, лимит пунктов, акцент, «закрывать после действия»;
- тёмный интерфейс в едином визуальном языке с меню: скруглённые поля и
  кнопки, акцентная «Сохранить», карточки с тонкой рамкой;
- изменения применяются после «Сохранить».

## Лог

`%LOCALAPPDATA%\Strofas\strofas.log` — старт, горячки, запуски/остановки,
fps живого фона при закрытии, ошибки; ротация при 512 КБ.

## Известные ограничения

- Полноэкранные exclusive-игры могут перекрывать меню (Topmost не всегда
  работает поверх таких окон).
- Если запущенная программа перехватывает фокус, меню закроется — это
  штатное поведение (переключение фокуса).
- Второй экземпляр запускается и молча завершается (одиночный экземпляр).
- Горячка может конфликтовать с уже занятой комбинацией — тогда в лог
  попадёт запись, и меню открывается из трея.
- На Win11 25H2 системные акрил-API (`SetWindowCompositionAttribute`,
  `DWMWA_SYSTEMBACKDROP_TYPE`) для layered-окон недоступны/нерендерятся —
  поэтому живой фон реализован захватом экрана + GPU-блюром.

## Технологии

C# / .NET 10 / WPF: безрамочное прозрачное оверлей-окно, `RegisterHotKey`,
`StreamGeometry` для лепестков, живой фон (GDI-захват в фоновом потоке +
`WriteableBitmap` + `BlurEffect`), трей через WinForms `NotifyIcon`,
конфиг на `System.Text.Json`.
